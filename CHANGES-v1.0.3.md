# SNDT v1.0.3

- Legend text (idea: ChaoDee): the legend's own rows (Planned, Under construction, Out-of-station interchange, Not in service) can say anything, with an optional description shown muted after the text, like a line's legend text and description; empty fields fall back to the translated default. Click the legend → "Legend text" lists only the rows the legend shows now. Stored in `legend.text` and `legend.desc` by row key (`planned`, `construction`, `xfer`, `nis`, `fac_<icon>`). The timeline's end legend board uses the same rows (`legendExtraRows`).
- Facilities in the legend (idea: ChaoDee): Legend → "Facilities": None (default), The ones used on this map, All, or Choose… (chips). Each shows the facility icon with its name, which can be changed in Legend text too (`legend.fac`, `legend.facPick`).
- Not in service: the X is drawn in the middle of the station's mark, so it stays on the mark when the mark sits on a line's lane away from the station's own point (it used to stay on the point). Custom station icons keep it on the point. (report: ChaoDee)
- Facility icon size (idea: ChaoDee): "Icon size" slider (50–300%) under Facilities in the Station panel, also for several stations at once (`station.iconScale`).
- Name line spacing (report: ChaoDee): each row of a name gets the height of its own text, so a big CJK row over a Latin row (孖角 / Twin Point) no longer leaves a wide gap. Names whose rows are all the same size look exactly as before.
- Creators: StarlightPixels joins as a tester; every creator has a quote under their name ("Yo tengo"); ChaoDee is now Lead Tester. The cards are three across (two on phones). Same in the handbook.
- Renaming a map (report: ChaoDee; the user picked the fix): click the map's name at the top left to rename it right there (Enter or clicking away keeps it, Esc cancels, undoable); the arrow next to it opens Your maps. The panel shown when nothing is selected is now called "This map" instead of "Map", so it is not mixed up with the Map/Timeline switch.
- Creators: the thanks line now reads "And everyone else in the SNDT and Petrolavia communities, …" with the SNDT logo next to Petrolavia's (also in the handbook).
